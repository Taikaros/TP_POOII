Actor: Estudiante
==
Historia de Usuario

**Criterio de aceptacion** 
Dado que el estudiante se encuentra regular, cuando se intenta inscribir a la mesa el sistema genera un acta.

Actor: Docente

**Criterio de aceptacion**
