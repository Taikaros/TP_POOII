Estudiante
Como estudiante quiero inscribirme a una mesa de examen para avanzar con la carrera.
Como estudiante quiero inscribirme a una cursada para quedar regular o promecionar, además de sabes en que salon se dará la clase.
Como estudiante quiero saber mi estado académico para saber si me puedo iscribir a una mesa de examen.

Docente
Como Docente quiero integrar el tribunal de una mesa para evaluar a los alumnos inscriptos.
Como docente quiero estar asisgnado a una cursada para dar clases y formar a los alumnos.
Como docente quiero saber a que cargo estor asignado para saber las acciones que debo realizar.
Como docente quiero cargar las regularidades y rpmociones de los estudiantes en el acta para que se puedan inscribir a las mesas.

No docente 
Como no docente quiero gestionar las aulas asisgnadas para controlar los equipamientos de estas.
Como no docente quiero crear llamados a mesas para que los alumnos puedan avanzar en la carrera.
Como no docente quero gestionar las aulas asignadas para que no haya superposicion de horarios.
